# Phase 7c — الإشعارات: دراسة سير العمل وتجربة الاستخدام

> وثيقة تحليل قبل التنفيذ (2026-11-08). المرجع: PROJECT_MASTER_PROMPT §26، PRD F-NTF-01/02، ERD (notifications).
> قرار مؤكد: قناتان — داخل المنصة (دائماً) والبريد الإلكتروني عبر SMTP. مزود الإرسال قابل للتبديل (SMS أو WhatsApp لاحقاً).

## 1. الأهداف
1. **لا يفوت العميل ما يتطلب فعلاً منه**: دفع العربون، مهلة الفائز، طلب معلومات إضافية.
2. **مكان واحد للتاريخ**: صفحة «الإشعارات» تجمع كل ما حدث، وكل إشعار يقود إلى الصفحة التي يُتصرَّف منها.
3. **هدوء**: لا رسائل مكررة، ولا بريد لما لا يستحق (مثل «تم تجاوز مزايدتك» المتكرر)، ويمكن للعميل إيقاف البريد.
4. **موثوقية**: الإشعار يُنشأ في نفس معاملة الحدث (لا إشعار لحدث لم يُحفظ)، والبريد يُرسل بعد الحفظ عبر Celery مع إعادة محاولة، وفشله لا يمس العملية الأصلية.

## 2. القنوات
| القناة | متى | ملاحظات |
|---|---|---|
| داخل المنصة | كل الإشعارات | جرس في الرأس بعدد غير المقروء يتحدّث فوراً عبر `/ws/me/`، وصفحة `/notifications` |
| البريد | الأحداث المهمة فقط (عمود «بريد» أدناه) | إن كان للعميل بريد، ولم يوقفه، وكان البريد مفعّلاً على المنصة. نص عربي RTL مع رابط «افتح في المنصة» |
| SMS / WhatsApp | لاحقاً | نفس واجهة المرسِل؛ يُضاف مرسِل جديد دون تعديل الأحداث |

**قواعد**:
- لا يُشعَر المستخدم بما فعله بنفسه (إلغاء طلبه، سحب طلب المزاد).
- التذكيرات وقرب الانتهاء تُرسل مرة واحدة (مفتاح منع التكرار لكل مستخدم وحدث).
- النص يُحفظ لحظة الإنشاء (Snapshot)، فلا يتغير الإشعار القديم بتغيّر البيانات.

## 4. صفحة الإشعارات
- عنوان + «تعليم الكل كمقروء» (يظهر فقط إن وُجد غير مقروء).
- تبويبان: «الكل» و«غير المقروءة».
- كل عنصر: أيقونة حسب النوع، العنوان، سطر النص، الوقت النسبي/المطلق، ونقطة لغير المقروء. الضغط يعلّمه مقروءاً وينتقل إلى رابطه.
- «عرض المزيد» للتحميل التدريجي.
- الحالات: تحميل (هيكل)، فارغ («لا إشعارات بعد» مع شرح ما سيظهر هنا)، فارغ في «غير المقروءة» («قرأت كل شيء»)، خطأ مع «إعادة المحاولة».
- **تفضيل البريد** في أسفل الصفحة: مفتاح «أرسل نسخة بالبريد للأحداث المهمة».
  - لا بريد في الحساب ← المفتاح معطّل مع رابط «أضف بريدك في صفحة الحساب».
  - البريد غير مفعّل على المنصة ← يُخفى القسم.

## 5. الجرس
- للمستخدم المسجّل فقط، بجانب العربة، ويظهر على الهاتف أيضاً (ليس داخل القائمة فقط).
- الشارة بعدد غير المقروء (9+ عند التجاوز)، و`aria-label` يقرأ العدد.
- يتحدّث فوراً عند وصول إشعار، ويُعاد جلبه عند العودة إلى التبويب.

## 6. التشغيل
- إعدادات SMTP من البيئة: `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `EMAIL_USE_TLS`/`EMAIL_USE_SSL`, `DEFAULT_FROM_EMAIL`، و`NOTIFICATIONS_EMAIL_ENABLED`، و`SITE_URL` لبناء الروابط.
- الإنتاج يرفض تفعيل البريد بمرسِل الـ console.
- أمر `send_test_email <address>` للتحقق من SMTP عند النشر.
- حالة البريد محفوظة لكل إشعار (لا يحتاج/بانتظار/أُرسل/فشل) مع آخر خطأ، للدعم.
- تنظيف تلقائي للإشعارات المقروءة الأقدم من 180 يوماً.
